2.AI-projektleder og fælles videnbase

Orkestrator: Claude Code (Opus)

Forstår opgaven, planlægger, fordeler til agenterne, bygger, tester og rapporterer.

  • Opgaveanalyse og plan (Plan Mode ved nye features)
  • Tildeler agenter og styrer rækkefølgen (ingen GPU-kollisioner)
  • Kvalitetssikring: læser hver agents resultat og diff
  • Bygger med Build.bat, kører testflag og billedserier
  • Rapporterer på dansk og fører historikken

Fælles videnbase

  • AGENTS.md / CLAUDE.md: regler for alle agenter
  • Docs/: historik, Backlog, TestFlags, CampaignLog
  • Reference/: uniformer, faner, kanoner, BILLEDLISTE.md
  • Data/Campaign1851/: historiske tal (1825 og 1851)
  • Hukommelse: dine tidligere ønsker og beslutninger

4.Lokalt værktøjslag

Pinokio: kører lokale AI-apps (D:\pinokio)

Hunyuan3D-2 LowVRAM: billede → teksturert 3D-figur; hovedværktøj til soldater
ComfyUI Image to 3D: TRELLIS2 (3D i høj kvalitet), GeometryPack (rens mesh), UniRig (auto-skelet)
Stable Fast 3D: hurtige rekvisitter: kugle, visker, ladestok
AniGen: animerbar figur fra ét billede; kandidat til heste
Puppeteer Auto-Rigger: skelet, skinning og FBX-eksport
Mesh2Motion: auto-rig og animationsprøve i browseren
ComfyUI: konceptbilleder, multiview-referencer, teksturer
Fooocus: hurtige konceptskitser
Stable Diffusion Forge: inpainting, ikoner, kortgrafik
FaceFusion: variation i portrætter og ansigter
FramePack Studio: billede → video som bevægelsesreference
Wan2GP: AI-video: referenceklip og trailer
