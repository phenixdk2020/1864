# PROJECT 1864 — Designmanual v00.02.00

## 20. Befolkning, økonomi, udvikling og militære institutioner

Slutversionen skal simulere det samfund og den militære institution, som gør krig mulig. Økonomi og udvikling må ikke blive et separat city-builder-spil, men de skal være konkrete nok til, at mangel på arbejdskraft, heste, kul, jern, våben, medicinsk kapacitet eller transport kan forklare, hvorfor en militær plan lykkes eller fejler.

> **KERNEPRINCIP:** Befolkning → arbejdskraft → landbrug/industri → skatter/varer → statens budget og lagre → rekruttering/udrustning/træning → operationer → tab → tilbagevirkning på befolkning og økonomi. Systemet skal være cirkulært og persistent.

### 20.1 Befolkning, husholdninger og arbejdsstyrke

Befolkningen skal eksistere regionalt og opdeles i relevante kategorier frem for én national manpower-pool. Militær mobilisering reducerer den civile arbejdsstyrke og kan derfor påvirke høst, industri, transport og skatteindtægt.

- Regional population med alder, køn, urban/rural, beskæftigelse og militær status på et passende aggregeret niveau.
- Arbejdskraft fordeles mellem landbrug, råstofudvinding, industri, transport, offentlig administration og militær.
- Krigstab, sygdom, emigration, migration og mobilisering ændrer langsigtet demografi og produktionskapacitet.
- Reservister er både militær ressource og civil arbejdskraft; længere mobilisering har en reel opportunity cost.

| Population-status | Spilbetydning |
| --- | --- |
| Civil arbejdsstyrke | Producerer varer, skattebase og transportkapacitet. |
| Værnepligtig årgang | Kan udskrives efter landets historiske regler. |
| Aktiv soldat | Indgår i stående hær eller aktiv tjeneste. |
| Reserve | Har tidligere træning og kan mobiliseres hurtigere end nye rekrutter. |
| Frivillig | Tilmelder sig uden ordinær udskrivning; kvalitet afhænger af baggrund og træning. |
| Invalid/veteran | Kan være ude af felttjeneste, men påvirke tradition, politik eller uddannelse. |

### 20.2 Landbrug, råstoffer og strategiske varer

Spillet skal have et begrænset sæt strategiske ressourcer, hvor hver ressource har en tydelig funktion. Målet er ikke hundredvis af handelsvarer, men at gøre forsyning, industrialisering og national sårbarhed forståelig.

| Ressource/vare | Primær anvendelse |
| --- | --- |
| Penge / statskredit | Løn, byggeri, import, militær, subsidier, renter og offentlige investeringer. |
| Fødevarer / korn | Civilbefolkning, garnisoner, hære, eksport og reservebeholdninger. |
| Heste | Kavaleri, artilleri, ambulancer, forsyningsvogne, officerer og transport. |
| Træ | Byggeri, jernbane, broer, vogne, skibsbygning og feltbefæstning. |
| Kul | Dampkraft, industri, jernbaner og dampskibe. |
| Jern / metal | Våben, maskiner, skinner, artilleri og materiel. |
| Byggematerialer | Sten, tegl, kalk mv. abstraheres til regional/national byggekapacitet. |
| Tekstiler / læder | Uniformer, telte, seletøj og civil efterspørgsel. |
| Krudt / ammunition | Militært forbrug, lagres fysisk og transporteres til depoter/enheder. |

- Gårde producerer fødevarer, dyr/heste og eksportoverskud afhængigt af jord, arbejdskraft, sæson og vejr.
- Miner, skove og andre råstofkilder er geografiske og kan udvikles med investeringer og infrastruktur.
- Mobilisering før høst eller mangel på heste kan sænke civil produktion; hæren konkurrerer med økonomien om de samme kapaciteter.

### 20.3 Byer, havne og regional udvikling

Byer skal være økonomiske, administrative og logistiske knudepunkter. Spilleren investerer på strategisk niveau i kapaciteter, mens meget civil vækst kan ske organisk gennem befolkning, handel, infrastruktur og privat kapital.

| Bykapacitet | Eksempel på effekt |
| --- | --- |
| Commerce | Handel, told, lager og markedsadgang. |
| Industry | Tilgængelig fabriks- og værkstedskapacitet. |
| Infrastructure | Vej, jernbane, telegraf, lager og transport throughput. |
| Port | Import/eksport, søtransport, flådelogistik og blokadeeffekt. |
| Arsenal | Lager, reparation og militær produktion. |
| Hospital | Behandlings- og recovery-kapacitet. |
| Education | Officerer, teknikere, administration og innovationshastighed. |
| Fortifications | Permanent defensiv værdi og behov for belejring. |

Udbygning skal tage måneder eller år og kræve penge, materialer, arbejdskraft og i nogle tilfælde importerede maskiner. En ny jernbane eller havn kan ændre en regions økonomiske tyngde og militære betydning.

### 20.4 Industri, produktionskæder og militære lagre

Våben og materiel skal produceres og eksistere som lagre. Mobilisering må derfor kunne blive begrænset af manglende rifler, ammunition, uniformer, heste eller artilleri – selv når der findes mennesker nok.

Eksempel på kæde: jern/kul → jernværk/maskinværksted → bearbejdet metal/maskinkapacitet → arsenal/riffelproduktion/artilleriværk → nationalt lager → depot → regiment.

- Våben beholdes som faktiske modeller/typer med årgang, kvalitet, lagerantal og kompatibel ammunition.
- Artilleripjecer, vogne og større materiel bør som udgangspunkt være konkrete inventory-objekter eller batches, ikke kun abstrakte modifiers.
- Reparation og vedligehold konkurrerer om industriel kapacitet med nyproduktion.
- Import kan lukke kapacitetsgab hurtigere, men gør landet afhængigt af udenrigshandel og søveje.

### 20.5 Handel, markeder og udenlandske indkøb

International handel skal forbinde økonomi, diplomati og flåde. Varer kan handles via kontrakter eller marked; priser påvirkes af udbud, efterspørgsel, told, transport, blokade og diplomatiske relationer.

- Handelsaftaler kan sænke told, sikre minimumsleverancer eller åbne adgang til bestemte markeder.
- Udenlandske indkøb kan omfatte rifler, artilleri, ammunition, maskinværktøj, kul, jern og skibe.
- Blokade eller krig kan afbryde kontrakter, gøre import dyrere og skabe indenlandske flaskehalse.
- Eksport giver valuta/skatteindtægt, men en stat kan i krise begrænse eksport af strategiske varer.

> **DESIGNVÆRN:** Markedet skal forklare strategiske mangeltilstande, men spilleren skal ikke være tvunget til at administrere hver enkelt handelsvogn. Handel simuleres i aggregerede flows og kontrakter med tydelig UI for årsag og konsekvens.

### 20.6 Statsbudget, skat, gæld og krigsfinansiering

Staten finansierer hær, flåde, infrastruktur, administration og investeringer gennem skatter, told, lån og eventuelle ekstraordinære krigstiltag. Krig skal kunne vindes militært og tabes finansielt.

- Budgetprioriteter: hær, flåde, befæstning, jernbane, uddannelse, sundhed, administration og subsidier.
- Gæld har renter og politiske/økonomiske konsekvenser; kreditværdighed påvirker lånevilkår.
- Skatter og rekvisitioner kan øge statens handlekraft på kort sigt, men skade legitimitet, forbrug eller lokal produktion.
- Militære reformer og intensiv træning skal have løbende fredstidsomkostninger.

### 20.7 Forskning, teknologi, doktrin og adoption

Teknologisk udvikling skal være mere end et research-point-træ. Der skelnes mellem viden/opfindelse, afprøvning, politisk beslutning, industriel tooling, masseproduktion, uddannelse og faktisk adoption i enhederne.

| Udviklingsområde | Eksempler |
| --- | --- |
| Våbenteknologi | Bagladning, riflede våben, ammunition, artilleri og projektiler. |
| Militær doktrin | Skirmish, staff work, artillery doctrine, mobilisation og combined arms. |
| Industri | Dampkraft, maskinværktøj, metalbearbejdning og standardisering. |
| Infrastruktur | Jernbane, telegraf, broer, havne og logistiske systemer. |
| Samfund/stat | Administration, uddannelse, sanitet, finansiering og rekrutteringssystemer. |

Et land kan kende en teknologi uden at have råd eller industriel kapacitet til at udstyre hele hæren med den. Ældre materiel kan derfor eksistere parallelt med moderne materiel i samme hær.

### 20.8 Rekruttering, værnepligt, frivillige og mobilisering

Rekrutteringssystemet er nation-specifikt. Danmark skal ved 1864 afspejle den almindelige værnepligt etableret i 1848–49, mens andre lande kan have andre kombinationer af stående hær, reserve, Landwehr, indelningssystem, frivillige eller andre institutioner. Historiske regler skal være datadrevne og kunne ændres ved reformer.

| Kategori | Behandling i simulationen |
| --- | --- |
| Frivillige | Tilmelder sig uden ordinær udskrivning; antal påvirkes af patriotisme, krigsmål, prestige og situation. |
| Værnepligtige | Udskrives efter nationale alders-, session- og tjenesteregler. |
| Aktivt personel | Har højere readiness og kan fungere som cadre for mobiliserede enheder. |
| Reserve | Tidligere uddannede soldater, der kræver indkaldelse, transport, udrustning og sammenøvelse. |
| Nye rekrutter | Kræver basic training før de bør tælle som kampklare replacements. |

Mobilisering er en pipeline: indkaldelse → rejse til mødeplads → registrering → udrustning → organisatorisk indplacering → sammenøvelse → operativ readiness. Klik på “mobiliser” må aldrig teleportere fuldt kampklare soldater til fronten.

### 20.9 Enhedstræning, readiness, erfaring og replacements

Training, readiness og combat experience er separate værdier. En eliteenhed kan være dårligt mobiliseret og dermed have lav readiness; en ny mobiliseret enhed kan stå fuldt samlet, men være dårligt trænet.

| Træningsdimension | Eksempel på taktisk/operationel effekt |
| --- | --- |
| Basic Training | Grundlæggende våbenhåndtering og disciplin. |
| Drill | Formationer, march, vendinger og deployering. |
| Marksmanship | Præcision og afstandsbedømmelse. |
| Fire Discipline | Ildåbning, salver og ammunitionsforbrug. |
| Fieldcraft | Dækning, skirmishing og terrænbrug. |
| Cohesion Training | Evne til at bevare/reorganisere formation. |
| Endurance | March og modstandsdygtighed mod fatigue. |
| Assault | Stormangreb, bajonet og nærkamp. |
| Entrenchment | Feltbefæstning og arbejdsdisciplin. |

- Fredstidstræning kan være garnison/drill, feltøvelse, live-fire, specialisttræning og større årlige manøvrer.
- Træning koster penge, ammunition, heste, materielslitage og arbejdstid; sparepolitik i fredstid kan derfor mærkes i krigen.
- Replacements fortynde veteranandel, NCO-kvalitet, erfaring og cohesion, indtil enheden har tid til at integrere dem.
- Regimentets headcount kan genskabes hurtigt; institutionel kvalitet kan tage år at genopbygge.

### 20.10 Lederudvikling, officersuddannelse og fredstidskarriere

Officerer udvikles gennem uddannelse, stabstjeneste, øvelser, feltkommando og kamp. Skills, personlighed og erfaring skal holdes adskilt: personlighed ændres langsomt, mens taktiske/stabsmæssige færdigheder kan forbedres gennem målrettet karriere.

- Militærakademier og stabsuddannelse har begrænset kapacitet og kan udbygges.
- Store manøvrer træner både enheder og kommandokæden: staff work, ordreformidling, logistik, initiative og coordination.
- Forfremmelse kan vægte anciennitet, merit eller politisk indflydelse og dermed skabe forskellige officerskorps.
- Mentor/stabstjeneste under dygtige generaler kan udvikle yngre officerer.
- Kampoplevelse kan forbedre judgement, men erfaring kan også skabe overdreven aggression, forsigtighed eller doktrinær bias.

### 20.11 Casualties, sårede, sygdom og sanitet

Casualties skal opdeles i killed, wounded, missing, captured, deserted og sick. Wounded er ikke permanent tab: nogle vender tilbage efter dage eller måneder, nogle bliver invalideret, og nogle dør senere af deres sår.

Battlefield → opsamling → regimental aid / kirurg → feltlazaret → større hospital → return to duty / invalid / death

- Sårede kategoriseres som walking wounded, transportable og immobile med forskellig evakueringskapacitet.
- Lazaretkapacitet, læger, medicinske forsyninger, rent vand, transport og overbelægning påvirker recovery og mortalitet.
- Sygdom simuleres separat og påvirkes af lejrforhold, ernæring, årstid, vejr, sanitet og overfyldning.
- Sanitetstjenesten skal kunne være en organisatorisk styrke, der opbygges gennem udstyr, personel og erfaring.

Historisk note: Den første Genèvekonvention blev vedtaget 22. august 1864 og fastlagde bl.a. princippet om, at sårede og syge kombattanter skulle samles op og behandles uden hensyn til nationalitet. Scenarier før dette tidspunkt må ikke automatisk anvende senere folkeretlige standarder.

### 20.12 Krigsfanger, savnede, efterladte sårede og hjemsendelse

Hvis en hær forlader slagmarken, bliver alle sårede ikke automatisk fanger. Resultatet afhænger af, hvor mange der kan gå, hvor mange der evakueres, hvor længe tilbagetoget dækkes, transportkapacitet og hvem der kontrollerer området bagefter.

- Efterladte ubevægelige sårede kan komme under fjendtlig kontrol og registreres som wounded POW frem for killed.
- Unwounded captured, wounded captured, missing og deserters holdes som separate statusser, som senere kan afklares.
- POW-pools har nationalitet, officer/enlisted-status, helbred, fangested og mulig senere udveksling, parole eller hjemsendelse.
- Efter-slaget-rapporten kan gradvist opdatere “missing” til killed, prisoner, hospitalised eller returned, så informationsusikkerhed også findes i personeltab.

### 20.13 Regimental lineage, kronik, fane og battle honours

Regimenter og andre navngivne formationer skal være vedvarende institutioner med egen historie. Historisk lineage ved campaign start suppleres af en dynamisk kronik over spillerens alternative historie.

| Historikfelt | Eksempel |
| --- | --- |
| Established / lineage | Oprettelsesdato, navneskift, fusioner og forgængere. |
| Home / garrison | Traditionel tilknytning og rekrutteringsområde. |
| Commanders | Dato-valideret chefhistorik. |
| Battles | Deltagelse, styrke, tab, rolle og resultat. |
| Battle honours | Historiske og dynamisk tildelte hædersbevisninger. |
| Colours / standards | Fane-id, udstedelsesdato, fysisk status, damage og capture-history. |
| Tradition | Afledt institutionel værdi fra veteraner, NCO-kadre, historie og kontinuitet. |

Eksempel på historisk grounding: Danske Livregiment blev oprettet 7. december 1763. I 1864-scenariet skal navn/organisation følge den korrekte samtidige designation og lineage, mens UI kan vise den længere regimentshistorie.

Fanen skal være et faktisk 3D-objekt i taktiske slag. Tabet eller erobringen af en fane er sjældent, men kan registreres permanent i regimentskronikken og påvirke prestige/tradition. Battle honours er historiske hædersmarkører og skal ikke fungere som simple permanente +attack-bonusser.

### 20.14 Personlige service records, medaljer og hæder

Officerer og relevante navngivne personer kan have en service record med poster for ansættelse, forfremmelser, sår, fangenskab, slag, commendations og dekorationer. Det gør det muligt at følge en kaptajn i 1848, som senere bliver brigadechef i 1864.

- Dekorationer og hædersbevisninger tildeles gennem historiske regler/events eller dynamiske criteria, ikke tilfældige loot-systemer.
- Service records skal være datadrevne og kunne refereres fra regimentskronikken og battle reports.
- Døde, invaliderede, pensionerede og tilfangetagne officerer forbliver i historikdatabasen, selv når de ikke længere er aktive.

### 20.15 Unit traits, earned perks og formation specialisations

Spillet skal skelne mellem tre lag: (A) enhedens optjente traits, (B) større formationers organisatoriske specialiseringer og support-perks, og (C) midlertidige states. Dette undgår et kunstigt RPG-system, men bevarer tydelig specialisering og progression.

| Lag | Hvordan det opstår | Eksempler |
| --- | --- | --- |
| Unit traits / earned perks | Træning, historie og faktisk kampadfærd | Well Drilled, Skilled Marksmen, Steady Under Fire, Veteran Defenders. |
| Formation specialisation | Bevidst investering i organisation, personel, udstyr og træning | Flying Column, Ambulance Service, Pontoon Train, Skilled Cartographers, Sappers & Miners. |
| Temporary state | Aktuel situation | Exhausted, Victorious, Battle Shaken, Short of Ammunition. |

- Perks må som hovedregel ikke købes med generiske XP-point. Enheden/formationen skal opfylde historisk/plausibelt begrundede krav.
- Formation specialisations kan have 2–3 erfaringsniveauer og kræve fortsat personel/udstyr for at bevare fuld effekt.
- Flying Column kan eksempelvis kræve erfarne stabe, quartermasters, transportdisciplin og hestekapacitet; Ambulance Service kræver medicinsk personel, vogne, hospitaler og faktisk sanitetserfaring.
- Pontoon Train skal repræsentere fysisk pontonmateriel og ingeniørpersonel; mistes materiellet, reduceres eller suspenderes kapaciteten.
- Regiments egne perks kan svækkes ved enorme tab og mange uerfarne replacements, fordi den institutionelle erfaring fortyndes.
