# PROJECT 1864 — Designmanual v00.02.08

## 13. Overgang til taktisk 3D-slag

Et encounter kan løses på tre måder: Fight, Delegate eller Auto-resolve. Alle tre bruger samme combat model og samme enhedsdata; forskellen er graden af spillerkontrol og simuleringsdetalje.

| Mode | Beskrivelse |
| --- | --- |
| Fight | Spilleren overtager taktisk slag. Real-time med pause/hastighed. Strategisk klokke fastfryses ved start og fremskrives til slagets sluttid. |
| Delegate | Tactical AI fører spillerens side. Spilleren kan observere og eventuelt have begrænset interventionsmulighed afhængigt af designindstilling. |
| Auto-resolve | Combat model afvikles uden 3D-visualisering, men med samme styrker, terræn, commanders, ammunition, morale og retreat constraints. |

### 13.1 Slagmarkens data

- Slagets geografiske center, orientation og boundaries kommer fra strategisk encounter.
- Terrain generator/importer bruger elevation, vejnet, skov, vandløb, bebyggelse og nøgleobjekter fra området.
- Strategiske befæstninger og field works overføres til 3D-kortet på deres faktiske positioner eller så tæt historiske data tillader.
- Tid på dagen og vejret er strategiske værdier, ikke tilfældige taktiske presets.
- Deployment zones bestemmes af approach vectors, march columns, pickets og surprise state – ikke symmetriske “spawn zones”.

## 14. Taktisk kommando og enhedsadfærd

Spilleren bør normalt kommandere brigade/regiment/bataljon, ikke individuelle figurer. Kommandoen er mission-baseret, men direkte formation- og fire-orders er tilgængelige på bataljonsniveau for spillere der ønsker detaljen.

| Ordregruppe | Eksempler |
| --- | --- |
| Movement | March, advance, quick march, wheel, change facing, occupy, fall back, retreat. |
| Combat | Attack, defend, probe, counterattack, pursue, cease fire, fire at will, hold fire. |
| Formation | Line, column, extended/skirmish order, reserve depth, artillery limber/unlimber. |
| Posture | Aggressive, balanced, cautious; stand, kneel/prone hvor relevant; hold ground vs preserve force. |
| Field works | Use cover, dig in, hasty entrenchment, improve position, build barricade. |
| Command | Set objective, intent, restrictions, autonomy, rally point, reserve status. |

## 15. Infanteri, formationer og ildkamp

Ildkamp skal være afstands- og formationsbaseret. Våben har muzzle/ballistic egenskaber, men spillet behøver ikke simulere hver kugles aerodynamik fuldt fysisk. Combat kernel kan afgøre expected hit distribution og derefter visualisere repræsentative projektiler, muzzle flashes og impacts.

| Parameter | Indgår i kampberegning |
| --- | --- |
| Weapon | Kaliber/type, loading method, base reload/rate of fire, reliability, sighting, effective range. |
| Range | Kontinuerlig range curve, ikke kun “in range / out of range”. |
| Shooter state | Training/experience, fatigue, morale, cohesion, suppression, formation, stance, officer influence. |
| Target state | Formation density, movement, stance, cover, elevation, posture, smoke/visibility. |
| Environment | Weather, light, smoke, terrain, wind hvis relevant for artilleri. |
| Fire control | Volley, independent fire, target priority, ammunition conservation. |

### 15.1 Synlig skudafstand

Når en formation markeres, kan spilleren slå et range overlay til. Overlayet viser ikke falsk præcision, men zoner: optimal, effective, long og ineffective. Tooltips kan vise den konkrete hit-effect curve for våbentypen under aktuelle forhold.

### 15.2 Sortkrudtsrøg

- Muzzle smoke og artillery smoke akkumuleres lokalt efter volley intensity og vind.
- Røg reducerer LOS og accuracy, gør target identification vanskeligere og kan skjule movement.
- Røg er både grafik og simulation; den må ikke kun være particle effect.

### 15.3 Reload, våbentype og experience

Reload-tid er en egentlig combat-stat og må ikke være et universelt interval for alt infanteri.

- Hver våbenprofil har en **basis-reload**, som primært bestemmes af våbentype og loading method.
- Regimentets **experience/træning** modificerer basis-reload inden for et begrænset interval: høj experience giver hurtigere og mere rutineret ladning, mens lav experience giver langsommere cadence.
- Experience må ikke udviske teknologiske forskelle. Et hurtigere ladesystem skal fortsat have en reel fordel ved samme træningsniveau.
- **Stance påvirker reload afhængigt af loading method.** Et forladegevær er besværligere at lade helt liggende, mens et bagladevåben som Dreyse kan betjenes langt mere effektivt fra lav stilling.
- Morale, cohesion, fatigue, suppression, ammunitionstilstand og officer/fire discipline kan senere lægges oven på samme reload-model.
- P0A anvender komprimerede prototypeintervaller for at holde testslaget kort. Tallene er gameplay-tuning og må ikke læses som endelig historisk rounds-per-minute.

Den aktuelle P0A-reference bruger et riflet forladegevær som dansk prototypeprofil og et Dreyse-tændnålsgevær som preussisk prototypeprofil. Profilnavnene beskriver den tilsigtede loading-teknologi; endelige regimentsspecifikke våbenmodeller og historiske værdier skal komme fra weapon/OOB-databasen.

### 15.4 Salve-feedback

Når en salve giver positive resolved hits, skal battle-UI kort vise feedback over målet, fx **“Ramte 4”**.

- Feedbacken er kortvarig og følger ikke som permanent informationslabel.
- Salver kan resolve til 0 direkte hits; i så fald vises ingen `Ramte N`-tekst, men shock/suppression kan stadig påvirke målet.
- I P0A svarer `resolved hits` direkte til reduceret authoritative strength. Den senere casualty pipeline skal splitte resultatet i killed, wounded, missing/captured osv.; UI-teksten må derfor ikke fortolkes som “dræbte”.
- Den endelige realism-/fog-of-war-UI kan senere begrænse, estimere eller skjule præcisionen i feedbacken, men P0A viser det eksakte tal for gameplay-læsbarhed og QA.

### 15.5 Enhedsstatus, ammunition og tab

Når casualty- og ammunition-systemet indføres, skal den taktiske enhedsstatus mindst kunne vise:

- aktuelt kampdygtigt mandskab, fx **566 mænd**,
- samlede tab i slaget,
- separat antal **dræbte** og **sårede**,
- ammunition tilbage for enhedens aktive våbenprofil,
- morale, cohesion, fatigue og experience.

Datamodellen bruger **tab** som fællesbegreb for dræbte + sårede. Ordet **faldne** reserveres til dræbte, så UI og efter-slaget rapporter ikke blander begreberne. Et eksempel kan derfor være `566 mænd | Tab 30 (8 dræbte / 22 sårede) | Ammunition 18.420`.

Ammunition skal være en reel beholdning og ikke kun en boolesk `out of ammo`-state. Salver, skirmish fire og andre fire modes bruger ammunition efter faktisk deltagende styrke/våbentype, og ammunition kan genforsynes fra supply-elementer.

### 15.6 Cover, stance og survivability

Cover og kroppens stilling er centrale taktiske faktorer og skal behandles som faktisk geometry/state, ikke som en universel procentbonus.

- Eksisterende objekter som **hegn, stenmure, grøfter, jordvolde, bygninger, skovkanter og terrænfolder** kan give cover eller concealment.
- **Cover** reducerer sandsynligheden for fysisk træf; **concealment** gør målet sværere at observere/identificere. Et objekt kan give begge dele i forskellig grad.
- Cover er **retningsbestemt**. Et hegn eller brystværn foran formationen beskytter ikke automatisk mod flanke- eller bagholdsild.
- Enheden kan skifte mellem relevante stance-states, mindst **stående** og **liggende/prone**; senere kan knælende/skirmish-variationer tilføjes.
- Prone reducerer målprofil og dermed sandsynligheden for at blive ramt af håndvåben og flere former for artilleriild. Effekten afhænger af ammunitionstype, indfaldsvinkel, eksplosions-/fragmenteringsområde og terræn; prone er derfor ikke en universel artilleri-immunitet.
- Prone giver lavere bevægelseshastighed og påvirker formation/cohesion. Reaktion på nye ordrer tager tid, fordi formationen først skal rejse sig eller reorganisere.
- Loading method påvirker, hvor effektivt enheden kan skyde fra lav stilling: bagladevåben har en klar praktisk fordel i forhold til forladevåben.
- Direct artillery fire, canister, shell/shrapnel og senere explosive effects bruger forskellige cover/stance-modifiers i stedet for én fælles “artillery protection”-værdi.

## 16. Artilleri, kavaleri og ingeniører

### 16.1 Artilleri

- Kanoner vises som udgangspunkt 1:1; crew visualiseres i reduceret skala efter behov.
- Batterier har piece count, gun type, ammunition mix, crew, horses, limber state, experience og commander.
- Deployment, line of fire, elevation, target visibility, counter-battery og ammunition er centrale.
- Artilleri kan have fysisk projectiles/trajectories til visualisering, mens damage resolution optimeres i combat kernel.
- Kanoner kan blive **forladt, slået ud, ødelagt eller erobret**. Erobring kræver fysisk kontrol over positionen, og kanonen skifter ikke bare abstrakt ejer ved et morale-roll.
- Erobrede kanoner bevares som materiel efter slaget. Om de kan bruges under selve slaget afhænger af tilgængeligt crew, ammunition, træning og tid til at vende/klargøre stykket.

### 16.2 Kavaleri og dragoner

- Strategisk reconnaissance, screening, courier support, flank security og pursuit er mindst lige så vigtigt som charge.
- I taktiske slag kan cavalry dismount hvis historisk/type-mæssigt relevant, screen, charge broken formations og forfølge routs.
- **Dragoner skal kunne sidde af og skyde som fodtropper.** De har derfor mindst to taktiske states: mounted og dismounted.
- Ved afsiddet kamp skal hestene blive holdt samlet bag eller ved siden af enheden; remount kræver tid og kan forstyrres af fjendtlig ild, panik eller tab af hesteholdere.
- Mounted state giver mobilitet; dismounted state giver bedre mulighed for vedvarende ildkamp. Våbenprofil, formation og accuracy følger den konkrete dragontype og periode.
- Heste har fatigue, forage og casualty dimension; kavaleriets værdi falder hvis hestebestanden kollapser.

### 16.3 Ingeniører og field works

- Brobygning/ødelæggelse, field works, obstacle clearance, fortification repair og siege support.
- Engineering tasks kræver tid, tools/materials og beskyttelse; de kan afbrydes af kamp.
- Almindeligt infanteri kan etablere **hasty cover** som skyttehuller, lave jordvolde, simple brystværn eller improviserede barrikader, hvis terræn, tid og værktøj tillader det.
- Ingeniører kan bygge hurtigere, forbedre eksisterende stillinger og udføre mere komplekse arbejder.
- Field works har faktisk position, retning, construction progress, condition og cover value. De kan beskadiges af artilleri og senere repareres/forbedres.
- Enheder skal fysisk besætte eller ligge bag stillingen for at få beskyttelsen; cover følger ikke enheden som en permanent buff, når den forlader positionen.

### 16.4 Supply-vogne

Supply-vogne er fysiske taktiske/logistiske enheder og kan bære eksempelvis ammunition, mad, reservedele og andre forbrugsvarer.

- En supply-vogn har inventory, vogn, trækdyr og personel/driver som adskilte værdier.
- Den kan **erobres, forlades eller ødelægges**. Crew og trækdyr kan blive dræbt/såret; lasten kan gå tabt helt eller delvist.
- En erobret intakt vogn og dens brugbare last overgår til den side, som fysisk sikrer den, men brugbarheden afhænger af kompatibilitet, især ammunitionstype.
- Ammunition transporteret på vogn kan ved senere implementering have risiko for brand/sekundæreksplosioner ved kraftig beskydning.
- Tab af supply-vogne påvirker kampens ammunition og senere den strategiske forsyningssituation; de er derfor relevante mål, ikke dekorative props.

## 17. Moral, cohesion, fatigue og casualties

Kampen skal primært afgøres ved kampkraftens sammenbrud, ikke ved at en HP-bar går til nul. Personeltab er vigtige, men morale og cohesion bestemmer om en formation bliver stående.

| State | Betydning |
| --- | --- |
| Morale | Vilje til at fortsætte; påvirkes af tab, flanke, artillery, commander, venner der rout’er og success. |
| Cohesion | Evnen til at fungere som formation. Fald ved movement i svært terræn, melee, heavy fire og dårlig command. |
| Fatigue | Fysisk udmattelse; bygger op ved march, løb, kamp og søvnmangel. |
| Suppression / shock | Kortvarig combat pressure, især fra tæt eller tung ild. |
| Experience | Modificerer stability, reload/drill, fire discipline og reaction to surprise. |
| Readiness | Aggregat til strategisk UI; ikke en separat magisk resource men afledt af de øvrige værdier. |

- States kan være Steady → Concerned → Shaken → Wavering → Routed, men motoren bruger kontinuerlige værdier.
- Rout kan sprede sig via lokale morale shocks, især hvis routes, officers og formationer kolliderer.
- Prisoners og missing opstår især ved blocked retreat, collapse, cavalry pursuit og surrender – ikke kun ved casualties.
- Wounded kan senere returnere til tjeneste afhængigt af severity, hospitalsystem og kampagnens varighed.

## 18. Retreat, pursuit og efter-slaget

Et slag slutter ikke ved resultatskærmen. Enheder har faktiske exit routes. Hvis retreat corridor er blokeret, stiger risiko for surrender og materieltab. Vinderen skal beslutte om den vil forfølge med trætte formationer eller reorganisere.

| Efter-slaget output | Overføres til kampagnen |
| --- | --- |
| Personel | Killed, wounded, missing, captured, stragglers, return-to-duty pool. |
| Materiel | Ammunition, guns lost/captured, wagons, horses, weapons. |
| Tilstand | Morale, cohesion, fatigue, experience changes. |
| Officerer | Killed/wounded/captured, reputation, performance assessment. |
| Geografi | End positions, retreat routes, occupied objectives, forts/broer damaged. |
| Tid | Battle end timestamp; campaign resumes herfra. |

### 18.1 Battlefield salvage og erobret materiel

Efter et slag skal det kontrollerende hold kunne bjærge materiel fra slagmarken. Det gælder blandt andet:

- våben afleveret af fjender, der overgiver sig,
- våben fra dræbte og sårede,
- forladte eller erobrede kanoner og limbers,
- ammunition og forsyninger fra erobrede supply-vogne,
- heste, vogne og andet militært materiel, der stadig er brugbart.

Bjærgning er ikke 100 %. En del af våbnene og materiellet er ødelagt, tabt, forsvundet eller ubrugeligt. En **recoverable percentage** beregnes ud fra skadetype, hvem der kontrollerer området, hvor meget tid der er til rådighed, vejrlig, discipline og logistisk kapacitet.

Erobrede våben lægges ikke automatisk direkte ind i den vindende enheds ammunition. De registreres som materiel med våbentype, tilstand og ammunitionstype. Brug i egen hær kræver kompatibel ammunition, træning og eventuelt organisatorisk beslutning; ellers kan materiellet lagres, repareres, omfordeles eller senere sælges/skrottes.

## 19. Flåde, kystkrig og amfibiske operationer

Danmarks sømilitære position gør flåden central i 1864. Første version kan behandle flåden mere operationelt end landkampen, men den endelige version bør understøtte 3D eller detaljeret naval combat for større engagements.

- Naval task forces: blockade, escort, transport, patrol, bombardment, interception og amphibious support.
- Ports har capacity, repair, supply og vulnerability.
- Troop transport kræver ships, embarkation time, weather window og destination capacity.
- Stræder og kystbatterier påvirker movement og blockade.
- Naval command chain og admiraler bruger samme generiske officer-system, men med maritime skills.
