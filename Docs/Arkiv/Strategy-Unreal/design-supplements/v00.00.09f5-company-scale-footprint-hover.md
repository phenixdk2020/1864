# PROJECT 1864 — v00.00.09f5 company-scale / footprint / hover supplement

**Status:** Implemented TEST supplement  
**Branch:** `channel-test`  
**Prototype:** `v00.00.09f5`

## Purpose

This revision converts the current 1v1 isolation test from regiment-scale visuals to company-scale representation while retaining the existing internal `Regiment` class and identifiers for compatibility.

## Company strength

- The active Danish and Prussian test units represent **190-man companies**.
- Combat strength and visible men are intended to match 1:1 when the F9 display ratio is 1:1.
- Casualties remain actual losses; at 1:1 fallen display, one lost man produces one fallen visual record.
- Hover UI identifies the Danish test unit as `1. Kompagni - Sjællandske Livregiment` and the Prussian test unit as `8. Kompagni - Preussen`.

## 1851 line formation

For the 1851 Danish baseline, line infantry uses **3 ranks**.

A full 190-man company is therefore distributed approximately as 64 + 63 + 63 men. With prototype lateral spacing of 0.75 m, full-strength line frontage is approximately 48 m.

Two-rank line is not the 1851 Danish default. It is documented separately as a later doctrine/regulation research and adoption option.

## Battlefield scale

The tactical prototype now uses the design assumption:

`1 Unity world unit = 1 metre`

Soldier height, rank spacing, company frontage, selection collider, selected footprint and range visualisation should all be interpreted against the same scale.

## Fire ranges used in 09f5

The current TEST values are gameplay/reference values rather than final weapon-table data:

- Close: 100 m
- Effective/Medium: 200 m
- Long/Maximum visual band: 400 m

Final weapon profiles remain data-driven research work. The important 09f5 requirement is that the range cone is now dimensionally consistent with the battlefield metre scale and originates from the actual formation frontage rather than a fixed-width origin.

## Selection and fire footprint

`PrototypeUnitFootprint09F5` derives its geometry from current strength and current formation.

- BoxCollider follows the actual company footprint.
- The old circular selection disc is hidden.
- Selected units receive a rectangular outline around the real formation footprint.
- Line and Column therefore have different selected footprints.
- Close/Medium/Long fire fans begin across the actual formation front and are rebuilt when the formation changes.

## Soldier visual

`PrototypeBattleVisuals09F5` supersedes the 09f4 living/casualty renderer at runtime.

- 1:1 living men supported.
- Three-rank line for the 1851 test baseline.
- Compact six-abreast march column.
- Dark-blue Danish coat, light-blue trousers, white crossbelts, shako and equipment retained.
- Musket/rifle is visually extended and fitted with a clearly readable fixed bayonet.
- Reforming Line <-> Column remains a physical visual transition rather than instant slot teleportation.

## Floating text and flags

Formation-level floating `TextMesh` labels are suppressed in 09f5. The two physical flags remain the primary above-unit identifiers:

- national flag
- regimental/company colour

Detailed unit information is moved to hover UI rather than permanently floating over the company.

## Hover information

Hovering the company displays a compact information box with:

- unit name
- nation
- current / initial strength
- fallen/losses
- formation
- current AI/order state
- morale
- cohesion
- ammunition
- weapon profile
- effective and long range

## Time controls

Battle clock and simulation speed controls are reduced in size and moved to the **upper-right corner**.

## Retained systems

The following remain from the prior 09f branch:

- river crossing only through the fixed bridge
- scenery pass-through for the current navigation isolation test
- smooth physical Line/Column reforming
- smooth stationary facing turns
- F9 display scale controls
- Defend Here / Attack / Capture Here orders
- enemy HOLD until explicitly activated
- Dannebrog plus Danish regimental colour
