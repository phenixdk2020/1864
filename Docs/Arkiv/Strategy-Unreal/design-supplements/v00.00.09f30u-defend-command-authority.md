# v00.00.09f30u — Defend Command Authority & HQ Goal Conflict Fix

## QA evidence
Two F30S recordings showed a committed Division `FORSVAR HER` apparently settling/stopping, followed by repeated console activity.

The relevant pattern was:
- `DEF-STABILITY ... HqGoalStabilized=True`
- then `HQ-DEPTH ... Corrected=True`

This revealed a destination-ownership conflict rather than a single movement-speed problem.

## Root cause
During `DefendHere`:
1. `PrototypeDefensiveStability09F29Y` derives Major rear position from the committed defensive mission facing/bank.
2. `PrototypeHqDepthGuard09F29W` independently derives rear position from the nearest enemy direction.
3. Both could write `HqGoal`.
4. The higher execution-state logic saw an active HQ goal and could keep the order blue even after the combat formation had effectively settled.
5. Re-issuing the same order could reproduce the same ownership conflict.

## F30U authority rule
A committed defensive mission owns its HQ geometry.

### Major
If a battalion's current order is `DefendHere`, HqDepthGuard does not write that Major's HqGoal. DefensiveStability remains the owner.

### Regiment
If Regiment's current mission is `DefendHere`, HqDepthGuard does not write Regimental HQ goal. RegimentalHQ follows the committed mission-facing.

### Settled Major
If the Major is already within the defensive settle tolerance, DefensiveStability clears any remaining competing HqGoal regardless of the competing goal's location.

## Expected result
- no DEF-STABILITY/HQ-DEPTH tug-of-war during DefendHere;
- no repeated destination re-arming after settle;
- fewer/no repeated stabilization correction logs;
- blue execution-state can end normally;
- a second DefendHere order to a genuinely new point starts a fresh movement rather than restarting an unresolved goal conflict.

## QA
1. Give Division `FORSVAR HER` and a clear drag-facing.
2. Observe companies, Majors, Regiment HQ, Brigade/Division HQ and CAV settle.
3. Confirm no Major/Regiment `HQ-DEPTH Corrected=True` entries are generated while DefendHere is current.
4. Confirm `HasHqGoal` clears once the Major is physically settled.
5. Confirm order button returns red once physical execution has ended.
6. Re-issue DefendHere to another point and confirm normal fresh movement.
