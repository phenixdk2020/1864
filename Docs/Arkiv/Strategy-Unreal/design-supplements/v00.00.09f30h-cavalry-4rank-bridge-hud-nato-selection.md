# v00.00.09f30h — Cavalry 4-rank, bridge, HUD, NATO & selection hardening

## Locked formation decision
From F30H the prototype uses four ranks as the normal mounted cavalry line and the charge line. Normal manoeuvre/march column is four abreast. A bridge or other defile uses two abreast.

This is a PROJECT 1864 gameplay/design choice for the current 1:1 scale. It replaces the previous two-rank normal line in runtime.

## Physical reform
A formation order changes target slots, not the riders' positions instantly. Each rider moves toward the new slot. The HUD exposes reform progress. Charge speed is deliberately limited while the formation is still reforming.

## Bridge transaction
Bridge routing is a persistent transaction:
NearBank -> FarBank -> ExitBank -> Direct.
New AI/player goals update the final goal but do not cancel the active crossing. ExitBank distance is based on the length of the full two-abreast 1:1 column, preventing the head from reforming while its tail is still on the bridge.

## HUD
Cavalry uses the company-HUD visual baseline: same 90px height, header, section typography and green/red/neutral state language. Cavalry-specific content replaces infantry fire controls.

## NATO / names / selection
The authoritative semantic-zoom owner F29V now owns cavalry and higher-HQ counters. Gardehusar/Dragon use I/CAV with unit names. Brigade/Division use X/XX HQ with names. Close view also receives readable labels. Box marquee can select a cavalry or higher-HQ entity when no infantry unit is inside the selection box.

## Visual polish
F30H adds modest mounted-equipment detail while preserving 1:1 counts and avoiding a new parallel visual authority.

## QA status
F30H remains TEST until Unity 6000.6.0f1 compile/runtime QA confirms the bridge, reform, semantic counters, OOB and HUD behavior.
