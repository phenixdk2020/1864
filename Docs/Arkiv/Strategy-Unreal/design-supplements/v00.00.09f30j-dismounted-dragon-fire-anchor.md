# v00.00.09f30j — Dismounted Dragon fire, horse holders & formation-anchor fix

## Formation anchor
F30J makes formation slots, selection footprint, destination ghost and physical collider use the same anchor convention.

- four-rank Line is centered around the unit root;
- normal four-abreast Column is front-anchored and extends backwards;
- two-abreast bridge/defile column is likewise front-anchored;
- therefore box/collider center must be shifted behind the root for Column/bridge states.

This replaces F30I's mathematically centered box for all formations.

## Dragon dismount doctrine
For the current prototype:
- approximately 25% are horse holders;
- approximately 75% are the dismounted combat group;
- horse holders remain close to the horses;
- combat group forms a two-rank line about 18m forward.

The 25% ratio and 18m spacing are QA values and may later become doctrine/scenario data.

## Dismounted fire
Dismounted Dragon carbine fire uses the current infantry range-language for QA:
- Close 35m;
- Medium 70m;
- Long 100m;
- total cone 70deg (+/-35deg).

The combat group may fire only when:
- mode = Dismounted;
- mount/dismount transition is complete;
- physical reform is complete;
- action = HOLD;
- ammunition remains;
- a valid target is inside range/cone.

TEST fire cadence is 7s reload and 20 rounds/man. Firing creates directional smoke and resolves hits/shock on the Regiment target.
