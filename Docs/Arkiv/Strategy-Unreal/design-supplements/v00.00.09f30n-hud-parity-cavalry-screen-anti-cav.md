# v00.00.09f30n — HUD parity, cavalry screen/opportunity AI & anti-cavalry infantry reaction

## Purpose
F30N addresses three runtime observations from the 2026-09-19 QA recording:
1. Brigade/Division HUD was not a 1:1 visual copy of Regimental HQ.
2. Autonomous cavalry could route through hostile infantry while seeking a flank/rear point.
3. Enemy infantry did not react strongly enough to nearby Danish cavalry before charge contact.

## Higher-HQ HUD parity
Regimental HQ is the visual source of truth.

Brigade and Division now use the same:
- bottom panel theme;
- header theme, font and height;
- AI/doctrine button position and dimensions;
- two-line information block;
- info width calculation;
- six mission buttons in one row;
- button dimensions, spacing and palette.

Higher HQ keeps its own data and authority, but not a separate visual language.
Active/pending mission is indicated in the caption rather than with a separate blue/green/red palette.

## Cavalry autonomous attack sequence
Autonomous CAV uses:

**SCREEN -> OPPORTUNITY -> CHARGE**

### Screen
- move toward a flank/rear screen point;
- remain outside the hostile infantry body;
- do not charge merely because flank/rear geometry is available.

### Opportunity
A charge opportunity exists when at least one of these is true:
- friendly Danish infantry has the target in PrototypeAttackContact local fire-contact;
- target cohesion is materially degraded;
- target morale is materially degraded.

A ready Square remains a no-charge condition.

### Charge
If opportunity + flank/rear geometry + valid commit distance are all true, CAV may charge.

## Hostile infantry avoidance
Prussian infantry companies create avoidance bubbles for autonomous cavalry movement.

If the direct route to a higher-HQ staging point or flank/rear screen point intersects a hostile infantry bubble:
- CAV receives an intermediate detour waypoint;
- the detour waypoint is not treated as mission completion;
- after clearing the obstacle, CAV replans toward the original screen/staging objective.

This is prototype tactical avoidance, not final navmesh/pathfinding.

## Infantry reaction against cavalry
Prussian infantry can target Danish cavalry when:
- infantry is stationary;
- FirePolicy is not HOLD;
- CAV is inside the selected fire-policy range;
- CAV is inside the infantry fire arc.

The volley reuses normal infantry:
- reload cadence;
- range accuracy curve;
- smoke;
- firing-strength calculation;
- cohesion cost.

CAV receives:
- strength casualties;
- morale shock;
- cohesion shock.

The existing 1:1 mounted/dismounted visual lists are visibility-trimmed against CurrentStrength so musket casualties are also readable on the battlefield.

A materially effective volley may force an uncommitted CAV approach into FALTER.

## Square reaction
Mounted-threat assessment is now team-neutral.

Threat score remains lower for screening/maneuvering CAV and higher for a committed charge.
If an automatic Square already exists, continued mounted presence refreshes its threat timer so it does not reform to Line while the threat is still nearby.
