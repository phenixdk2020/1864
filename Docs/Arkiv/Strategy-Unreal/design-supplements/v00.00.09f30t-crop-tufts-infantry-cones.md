# v00.00.09f30t — Crop Tuft Visuals & Infantry Active Range Authority

## Purpose
F30T fixes two presentation defects found during close tactical QA: crop rows rendering as long yellow beams, and infantry CLOSE/MED/LONG cones not visually reflecting the selected fire policy.

## 1. Crop visual replacement
The F29Y crop mesh used long solid box segments. At close zoom these read as oversized timber-like beams rather than standing crop.

F30T replaces those segments with many short upright crossed crop tufts.

Properties:
- individual terrain-height sampling;
- deterministic micro-jitter;
- small deterministic height variation;
- crossed double-sided quads for tactical-camera readability;
- no long horizontal solid boxes;
- crop shadows no longer form oversized beam shadows;
- F29R remains authoritative for concealment and movement effects.

A new `CropFields09F30T` runtime root is created. Any prior `CropFields09F29Y` visual root is explicitly disabled so a Unity hot/domain reload cannot leave the old geometry active.

## 2. Infantry cone visual authority
The previous active-range emphasis in `Regiment.cs` was overwritten every frame by `PrototypeFireVisuals09F8.LateUpdate()`.

F30T moves the final visual state into that actual authority.

Visual hierarchy:
- selected fire policy range: alpha ~0.98 and width ~1.55x;
- non-selected physical ranges: alpha ~0.18 and width ~0.55x;
- HOLD: all bands use the faint/reference state.

This applies to Danish selected infantry and Prussian TEST/QA cones.

## 3. Enemy QA cones
Prussian infantry cones remain visible in TEST without player selection so range/facing/fire-policy can be inspected.

This is visualization only:
- no LOS is granted;
- no target is discovered;
- anti-CAV fire still requires LOS + range + cone;
- future normal gameplay will gate enemy cone visibility behind LOS/FOG.

## QA
1. Restart Play mode and inspect crop fields at close zoom: no long yellow beams.
2. Verify crop tufts conform locally to sloped terrain.
3. Select Danish infantry and switch CLOSE/MED/LONG; exactly the selected band is strongly emphasized.
4. Select HOLD; all ranges become faint references.
5. Inspect Prussian TEST cones without selection; active band is strongest.
6. Confirm QA cone visibility does not alter anti-CAV LOS/range/cone behaviour.
