# v00.00.09f29t – Interactive tactical map

## Formål
F29T gør det eksisterende F29P taktiske kort til et aktivt navigations- og selection-værktøj uden at ændre den etablerede command authority.

## OOB / selection-regel
Samme UX-regel gælder nu både OOB og minimap:

- Enkeltklik på eget kompagni/HQ vælger command entity uden at flytte kameraet.
- Dobbeltklik på samme enhed/HQ vælger og flytter kameraet bag enheden/HQ'et.
- Selection udsteder ikke i sig selv taktiske ordrer og bypasser ikke Kaptajn -> Major -> Oberstløjtnant authority.

## Taktisk kort
Det eksisterende kort fra F29P bevares som den visuelle renderer. F29T lægger interaktion ovenpå det samme map-rect og de samme dynamiske map-bounds.

### Klikadfærd
- Enkeltklik på dansk kompagni: vælg kompagniet, kamera uændret.
- Dobbeltklik på dansk kompagni: vælg kompagniet og placer kamera bag dets facing.
- Enkeltklik på Major A/B HQ: vælg Major-niveau, kamera uændret.
- Dobbeltklik på Major A/B HQ: vælg Major og placer kamera bag HQ.
- Enkeltklik på Oberstløjtnant/regiments-HQ: vælg regiment command level, kamera uændret.
- Dobbeltklik på regiments-HQ: vælg og placer kamera bag HQ.
- Enkeltklik på tomt kort eller fjendtlig markør: flyt kameraets fokus til den valgte kortposition.

## Pointer isolation
Et klik inde i minimappets kortflade må ikke samtidig blive fortolket som normal battlefield selection, box selection eller en gammel pending F9 ground/attack order.

F29T deaktiverer derfor de relevante legacy pointer handlers for den pågældende frame og genaktiverer dem bagefter. En pending taktisk ordre bevares; mapklikket må hverken udføre eller annullere den.

## Kortets symboler
- Dansk enhed: blå markør.
- Preussisk/fjendtlig enhed: rød markør.
- Valgt enhed: gul markør.
- Major HQ: cyan markør.
- Oberstløjtnant/regiments-HQ: gul/orange HQ-markør.
- Kamera: hvid markør + retning.
- Vej: brun linje.
- Flod: blå linje.
- Gule rektangler: crop fields fra F29R; de er terræn/concealment-zoner og ikke selection-zoner.

## Square-regression
F29T ændrer ikke Square-combat. F29S forbliver autoritativ for Square fire:

- 4 faste 90-graders faces: FRONT, RIGHT, REAR, LEFT.
- cirka 25 % af kompagniets ildkraft pr. face.
- separat target selection pr. face.
- separat reload clock pr. face.
- square heading låses, så formationen ikke roterer mod én trussel.
- gamle 360-graders range-ringe og normal forward cone undertrykkes i Square.
- Close/Medium/Long sektorvisualer tegnes pr. face, når Square er fire-ready og enheden er valgt med range-visning aktiv.
- F29S genbruger Regiment.FireVolley, så eksisterende accuracy, morale, terrain, smoke og casualty-processer fortsat er autoritative.
