# v00.00.09f30r — Dragon Fire Control

## Purpose
F30R adds explicit infantry-style fire-control to dismounted Dragon while preserving the F30Q command-state baseline.

## Runtime fire policies
When Dragon is dismounted, the cavalry HUD exposes four fire policies:

- `HOLD` — 0 m trigger range; no automatic target acquisition or firing.
- `CLOSE` — 35 m.
- `MED` — 70 m; default.
- `LONG` — 100 m.

The selected policy controls only the engagement threshold. Existing carbine combat rules remain authoritative:

- ±35° firing arc;
- ~7 second TEST reload;
- 20 rounds/man TEST ammunition;
- existing smoke;
- existing hit/shock resolution.

## HUD behaviour
- Fire-control buttons appear only for dismounted Dragon.
- Active policy is green; inactive choices remain red, matching the infantry control language.
- Mounted Dragon instead shows that carbine fire-control becomes available after `SID AF`.
- Mounted carbine fire remains intentionally unimplemented.

## Range visualization
All three physical reference cones remain visible while selected/dismounted. The currently active engagement band is emphasized; the non-selected bands remain faint reference geometry. HOLD leaves all bands as reference-only.

## Inherited F30Q baseline
F30R retains:
- pending/active officer orders in blue;
- BAL attack using both battalions forward;
- DEF whole-battalion reserve option;
- OFF flank-capable disposition;
- committed facing propagation;
- higher-HQ relative follow;
- Major/Regiment/Brigade/Division command zones;
- future `SPEJD HER` design deferred until true FOG/LOS.

## QA
1. Dismounted Dragon shows HOLD/CLOSE/MED/LONG.
2. MED is selected by default.
3. HOLD suppresses target acquisition and fire.
4. CLOSE does not fire beyond 35 m.
5. MED does not fire beyond 70 m.
6. LONG may engage to 100 m.
7. Targets outside ±35° arc are not engaged.
8. Ammo decreases after valid volleys.
9. Active cone is visually stronger than inactive reference cones.
10. Re-mounted Dragon no longer shows active fire-range buttons.
