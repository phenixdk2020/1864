# v00.00.09f30k — Auto march column, RMB facing, split Dragon selection & higher-HQ AI HUD

## Mounted automatic march formation
Automatic cavalry formation policy belongs to the shared cavalry core, not only Officer AI.

For a normal mounted MOVE with no enemy inside Long:
- >=140m remaining: automatic 4-abreast Column;
- <=90m remaining: deploy to 4-rank Line.

The two thresholds form hysteresis. A valid enemy inside current Long range forces Line immediately. Bridge routing has higher priority and still uses 2-abreast.

A player-selected formation is an explicit manual override and is not immediately replaced by automatic policy. HOLD or delegation back to Officer AI clears that override.

## RMB destination + facing
Cavalry now uses the infantry interaction pattern:
1. RMB down on destination;
2. hold RMB;
3. drag in desired final-facing direction;
4. release to commit.

A drag >=4m creates explicit final facing. The destination ghost and final unit orientation use the same facing.

## Dismounted Dragon selection
The previous single rectangle represented the complete horse-to-firing-line span and therefore contained a large empty center. F30K replaces it with:
- combat-line selection box;
- horse-holder selection box;
- thin connection line.

## Mount timing
SID AF remains approximately 2.25s. STIG OP/remount is approximately 4.5s to make recall and remount visually readable.

## Brigade/Division HUD + AI authority
Brigade and Division now expose:
- AI ON/OFF;
- DEF / BAL / OFF doctrine;
- mission orders.

Higher-HQ AI defaults OFF. In F30K this is a real authority/gating state rather than a decorative toggle. Attached cavalry Officer AI requires its current parent AI authority:
- Division parent -> Division AI;
- Brigade parent -> Brigade AI;
- Regiment parent -> Regimental AI;
- Major A/B parent -> corresponding Battalion AI.

Higher-HQ doctrine is passed into the existing Regimental order decomposition pipeline.
