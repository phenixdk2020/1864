# v00.00.09f9 – Combat QA

## Officer engagement distance
F9 fire policy defines when a company is allowed to open fire, not a mandatory standoff distance. An AI officer may therefore choose a closer engagement distance than the selected maximum fire policy if doctrine, aggressiveness, tactical skill and local decision noise support it.

Examples:
- CLOSE: fire is only permitted inside Close range.
- MEDIUM: fire is permitted out to Medium range, but the officer may close into Close before engaging.
- LONG: fire is permitted out to Long range, but the officer may still choose a shorter preferred engagement distance.

This distinction is intentional: the player defines fire-control intent, while the officer retains tactical discretion over exact engagement distance when AI is enabled.

## Hit-rate QA
The prior Close-range test produced roughly 1–3 casualties per volley because the legacy formula counts 58% of current strength as firing men and used prototype base accuracy around 0.014.

For 09f9 QA only:
- Danish base accuracy: 0.050
- Prussian base accuracy: 0.052
- Continuous distance accuracy curve retained
- Morale locked to 100 from 09f8
- Cohesion remains active

The intent is to make Close/Medium/Long casualty differences easier to observe before permanent weapon lethality values are designed.

## Particle velocity warning
`BlackPowderSmoke09F7` uses Velocity over Lifetime. Unity requires X/Y/Z MinMaxCurve values to use the same curve mode. 09f9 normalises all three axes to TwoConstants mode:
- X: 0 / 0
- Y: 0.10 / 0.45
- Z: 0 / 0

This removes the mode mismatch while retaining gentle upward black-powder drift.
