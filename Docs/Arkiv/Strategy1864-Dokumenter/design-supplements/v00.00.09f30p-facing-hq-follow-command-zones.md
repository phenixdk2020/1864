# v00.00.09f30p — Committed Facing, Higher HQ Follow & Command Zones

## Purpose
F30P fixes a command-orientation mismatch and extends the existing HQ command-zone model upward to Brigade and Division.

## 1. Committed facing is mission data
Click+drag facing is now passed into formation planning before slots are generated.

This applies to:
- Major/Battalion orders;
- Regiment orders;
- Brigade orders;
- Division orders.

For `FORSVAR HER`, the same committed facing drives:
- battalion lateral axis;
- company slots;
- company destination facing;
- Regiment-HQ rear position;
- attached cavalry support/reserve positions.

The previous post-hoc facing patch is no longer authoritative because it could draw one arrow while the layout had already been generated from another direction.

## 2. Higher HQ follow geometry
Higher HQ positions are now calculated relative to the committed formation-facing.

Removed world-space hacks:
- `+Vector3.forward * 75` on Brigade;
- `-Vector3.forward * 95` on Division.

Current QA follow values:
- Brigade: 120 m rear + 65 m relative lateral offset;
- Division: 145 m rear - 75 m relative lateral offset from Brigade;
- Brigade speed: 6.2 m/s;
- Division speed: 5.9 m/s.

These are prototype values and should be tuned from runtime recordings.

## 3. Command zones
Selected HQs show inner/outer command reach using terrain-following circles.

Current QA bands:
- Major/Battalion: 320 / 450 m;
- Regiment: 800 / 1100 m;
- Brigade: 1350 / 1850 m;
- Division: 2100 / 2850 m.

Only the selected HQ level shows its detailed command circles to reduce clutter.

## 4. Simulation meaning
In F30P the Brigade/Division rings are primarily visual/QA bands.

Long-term command reach affects:
- order and reaction delay;
- coordination;
- reserve/flank reassignment;
- recovery;
- information/report quality;
- courier/order lifecycle;
- fog-of-war reporting.

It does not directly modify weapon damage or musket accuracy.
