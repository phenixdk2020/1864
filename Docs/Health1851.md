# Sygdom, sårede og fanger (backlog 5 og 15)

## Sygdom
- **Hvem bliver syge:** de mænd, der er til stede.
  - I garnison bliver 0,02 % syge om dagen, i felten 0,1 %.
  - I felten fordobles det i regn, sne og tø.
  - Uden proviant fordobles det igen.
- **Koleraen i København**, juni–september 1853: garnisonen bliver syg 10 gange så hurtigt.
- **De syge** (`Sick`) er ikke med i enhedens mand. De vises i kolonnen "Syge" i vinduet HÆREN.
- **Lazarettet:**

  | | Tilbage til rækkerne pr. dag | Døde pr. dag |
  |---|---|---|
  | Almindeligt | 3 % | 0,4 % |
  | Med sanitetsvæsenet (forskning) eller et færdigt lazaret i garnisonsbyen | 5 % | 0,2 % |

  Mænd ud over etaten bliver hjemsendt.

## Tab i slag
| | Faldne | Sårede (til lazarettet) | Fangne |
|---|---|---|---|
| Sejr eller uafgjort | 25 % | 50 % | 25 % |
| Nederlag | 20 % | 35 % | 45 % |

Danskerne tager 20 % af fjendens tab til fange ved sejr, ellers 5 %.

## Fangeudveksling
- Ved freden kommer de danske fanger hjem som mandskab til amterne, og fjendens fanger løslades.
- Fangetallene gemmes i Supply-linjerne som `prisoners|danske|fjendtlige` og `sick|id|antal`.
